# Modernizing legacy web applications at Florida DEP

**Role:** Application Systems Programmer, September 2023–April 2026  
**Focus:** Classic ASP migration to PHP with CodeIgniter MVC

## The problem

At the Florida Department of Environmental Protection, I worked on existing business web
applications built with Classic ASP. The modernization work involved moving functionality
to PHP and CodeIgniter while maintaining the workflows people already relied on.

This was work on an existing system, with existing behavior to understand and preserve.
That made reading legacy code and tracing how a request moved through the application
an important part of the development work.

## My contribution

I contributed to migrating legacy application functionality into a PHP/CodeIgniter MVC
structure. The work drew on PHP, HTML, CSS, JavaScript, SQL, and an understanding of how
the original application behaved.

The central engineering task was translating working behavior into a different application
structure. It required reasoning about the relationship between request handling, data
access, and the page presented to the user.

## The result

The migration moved a substantial portion of the legacy functionality to the newer stack.
The CodeIgniter implementation provided an MVC structure for continued development and
maintenance. This experience strengthened my ability to investigate unfamiliar code,
work within an existing system, and connect backend changes to user-facing behavior.
